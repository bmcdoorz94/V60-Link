# Working on V60 Garage from your own computer

The GitHub repo is the whole project. Claude Code reads `CLAUDE.md` when it opens the folder, so there is nothing
else to prepare: clone, open, work, push.

Kyle is on Windows. Commands below are for PowerShell (right-click the Start button, then Terminal). Where the project's
other docs say `python3`, type `python` on Windows.

## 1. One-time setup
1. Install Git for Windows (git-scm.com, defaults are fine) and Python 3.12 or newer from python.org. In the Python installer tick "Add python.exe to PATH". Check in a new terminal: `git --version` and `python --version`.
2. Install Claude Code following Anthropic's Windows instructions at https://docs.claude.com (search "Claude Code"). Sign in with the same account you use here.
3. Clone the repo into a folder you will keep. Desktop is fine:
   ```
   cd $HOME\Desktop
   git clone https://github.com/bmcdoorz94/V60-Link.git
   ```
   That creates `Desktop\V60-Link` with the source (`src/`), tools, tests, docs and the built site.
4. Tell Git who you are, once:
   ```
   git config --global user.name "bmcdoorz94"
   git config --global user.email "kfitz719@gmail.com"
   ```
   The first push will ask you to sign in to GitHub (a browser window opens). Installing the GitHub CLI (`gh auth login`) makes that painless.

## 2. Each session
1. Open the folder in Claude Code (`cd $HOME\Desktop\V60-Link` then `claude`, or open the folder from the Claude desktop app's Code tab).
2. First message of a session, every time:
   > Read CLAUDE.md, docs/ROADMAP.md and docs/HANDOFF_STATE.md, pull the latest from GitHub, and tell me where things stand in plain words. Then wait for me.
   After that, say what you want in plain words, the same as here. Claude Code already knows the rules from `CLAUDE.md`: ask clarifying questions, cite sources, explain changes, build, test, push.
3. Claude builds with `python3 tools/build.py` and pushes to `main`; GitHub Pages serves it a minute or two later at https://bmcdoorz94.github.io/V60-Link/ (the `handoff` branch is rebuilt by GitHub at the same time).

## 3. Preview before pushing (optional)
```
python tools/build.py
python -m http.server 8000
```
then open http://localhost:8000 in a browser on the same computer. Bluetooth (Live link) still needs Bluefy on the phone.

## 4. Tests on your computer (optional)
Needs Node 20 or newer (nodejs.org). Then, once, inside the folder:
```
npm install playwright
npx playwright install chromium
```
Run any test with plain `node tests/regression.js` (no `PLAYWRIGHT_PATH` or `CHROMIUM_PATH` needed locally; those are only for the cloud session). `tests/scan.js`, `tests/tire.js` and `tests/docs.js` download Tesseract or pdf.js from jsDelivr the first time.

## 5. Things to keep straight
- Edit only `src/`, `tools/`, `tests/`, `docs/`, `CLAUDE.md`. The root `index.html`, `js/`, `sw.js`, `link.html` and `dist-artifact/` are build output and are regenerated by the build (locally or by the GitHub Action).
- Pull before you start (`git pull --rebase -X theirs origin main`; the first-message prompt above asks Claude to do it): the GitHub Action commits build output after every push, so your copy is behind by one commit most of the time.
- Never put the VIN, plate or chassis number in any file. The repo is public.
- Photos and documents you give Claude locally stay on your computer unless Claude is asked to add them to the app; the app itself blacks out personal details before storing anything.
- The cloud Claude session, Claude Code on your computer and a Gemini handoff all work from the same repo, so you can switch between them freely as long as each one pushes before you move on.
