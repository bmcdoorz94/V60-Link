# The V60 chats

Every claude.ai chat about the car, summarised so the project carries what was said and decided in them. Kyle chose digests over full transcripts on 2026-10-15 because this repo is public: the VIN, plate, chassis number, contact details, job and pay details are left out.

| Date | Chat | What it covers |
|---|---|---|
| Sept 2026 | [Getting started with cars and trucks](2026-09-getting-started.md) | Where it began: identifying the car and engine, the owner's manual, what to learn first. |
| Oct 10–14, 2026 | [Non-work ideas](2026-10-non-work-ideas.md) | The long chat where V60 Garage was built, from the first page to the redesign, the scanner, Live link on the car and the Texas inspection history. |
| Oct 14, 2026 | [v60 log file upload](2026-10-14-drive-log.md) | The first drive recording: lean at idle, near normal under load. |
| Oct 15, 2026 | [ASE certification tiers](2026-10-15-ase.md) | ASE tiers and fees, which led to the ASE article, the tool list and the certification track. |

Each digest lists what Kyle said, facts about the car with their sources, findings and advice (marked where no source was given), open questions, and what was built. The app's sourced content wins over anything said in a chat without a source. Later work happened in Claude Code sessions; see docs/ROADMAP.md and docs/HANDOFF_STATE.md.

When a new chat about the car happens, add a digest here with the same sections and the same privacy rules.
